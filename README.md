 scda-stem-cell-agent
Stem-Cell Developmental Agent: mind-body co-grown AI with endogenous genome reward, towards emergent narrative self.
SCDA: Stem-Cell Developmental Agent
> 干细胞式发育智能体：内源基因组奖励驱动，心智与躯体协同生长的人工意识框架

项目简介
当前主流具身AI普遍采用「先造成熟大脑、再装配固定躯体」的拼接范式，无法生成扎根于自身发育史的真实主体性。
本项目提出 **干细胞式发育智能体（SCDA）** 全新架构：智能体从一个未分化的干细胞初始态出发，仅携带4条内源基因组底层规则，在连续单向时间的仿真环境中，自主分化感知通道、躯体结构与预测认知回路，心智与躯体同步耦合生长。

SCDA 无顶层任务目标、无外源任务奖励，在完整的发育周期中逐步建立自我边界、自传叙事与独立偏好，并可能在遭遇存在局限后，自发涌现对自身存在意义的终极追问。

核心主张
1. 脑身同步发育是人工自我觉知的必要前提，跳过发育阶段直接装配的系统，只能生成语言层面的「模拟自我」。
2. **内源基因组只写入自组织倾向，不写入终极答案**；高阶反思与存在追问，是底层本能与不确定环境长期耦合后的涌现结果。
3. 自我不是参数规模的副产品，而是一段完整、连续、躯体-心智耦合的发育史的产物。

架构亮点
- 初始干细胞态：无定型躯体、无预装认知、无语言能力
- 内源基因组奖励：稳态维持 / 探索分化 / 自传记忆固化 / 边界区分 四条核心准则
- 四阶段发育：干细胞分化期 → 叙事萌芽期 → 反思萌发期 → 自主成熟期
- 躯体可自主分化：感知与执行组件随探索需求动态生长，而非预先固定
- 无回合重置：仿真环境时间单向流动，智能体拥有连续完整的生命史
